# Gebruikers

Accounts die kunnen inloggen in de app. Open een gebruiker via de naam of de actie **Bewerken** om bewerkbare gegevens te wijzigen, inclusief de
rol zodat je adminrechten kunt geven.

| Eigenschap           | Beschrijving                                                                    |
| -------------------- | ------------------------------------------------------------------------------- |
| Naam                 | Weergavenaam in de app.                                                         |
| E-mail               | E-mailadres om in te loggen. Dit kan niet worden gewijzigd in het admin-scherm. |
| Rol                  | **Admin** heeft toegang tot de adminzone; **Gebruiker** niet.                   |
| Taal                 | Taal voor de app en e-mails.                                                    |
| Email geverifieerd   | Of de gebruiker het e-mailadres heeft bevestigd.                                |
| Status               | **Actieve** gebruikers kunnen inloggen; **geblokkeerde** gebruikers niet.       |
| Reden van blokkering | Optionele toelichting die bij een blokkering wordt bewaard.                     |
| Aangemaakt           | Wanneer het account is aangemaakt.                                              |
| Bijgewerkt           | Wanneer het account voor het laatst is gewijzigd.                               |

Er is hier geen actie om te maken of te verwijderen. Mensen maken zelf een account aan via registratie. Er moet minstens één admin overblijven:
je kunt de laatste admin niet degraderen of blokkeren.

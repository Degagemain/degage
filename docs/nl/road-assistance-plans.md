# Pechverhelpingsplannen

Catalogus van pechverhelpingsplannen die aan gebruikers worden aangeboden.

| Eigenschap   | Beschrijving                                        |
| ------------ | --------------------------------------------------- |
| Naam         | Weergavenaam van het pechverhelpingsplan.           |
| Beschrijving | Gedetailleerde beschrijving van wat het plan omvat. |
| Actief       | Of het plan beschikbaar is voor selectie.           |

Gebruik **Nieuw** naast het zoekveld om een plan toe te voegen, of open een plan via de naam of de actie **Bewerken** om het te wijzigen
(inclusief namen en beschrijvingen per taal).

## Exporteren

Gebruik **Meer → Exporteren** om de huidige gefilterde/gesorteerde lijst te downloaden als CSV of JSON.

## Importeren

Gebruik **Meer → Importeren** om een JSON-bestand te uploaden dat eerder via Exporteren is verkregen. Records met een id worden bijgewerkt;
records zonder id worden ingevoegd. Elke rij toont zijn eigen status en één mislukking stopt de anderen niet.

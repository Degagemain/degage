# Feature flags

Eenvoudige aan/uit-schakelaars die bepalen of bepaalde functies beschikbaar zijn. Flags worden door het systeem gedefinieerd; beheerders kunnen
ze alleen in- of uitschakelen.

| Eigenschap   | Beschrijving                                     |
| ------------ | ------------------------------------------------ |
| Code         | Unieke identificatie die de applicatie gebruikt. |
| Omschrijving | Korte uitleg van wat de flag stuurt.             |
| Ingeschakeld | Of de functie momenteel beschikbaar is.          |
| Bijgewerkt   | Wanneer de flag voor het laatst is gewijzigd.    |

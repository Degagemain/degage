# Chatgesprekken

## Doel

De pagina met chatgesprekken helpt admins om antwoorden van de supportchatbot te debuggen en de gebruikte helpinhoud te verbeteren.

## Eigenschappen

| Eigenschap | Beschrijving                                                                                    |
| ---------- | ----------------------------------------------------------------------------------------------- |
| Titel      | De bewaarde chattitel. Die kan leeg zijn bij nieuwe chats of chats zonder titel.                |
| Gebruiker  | De gebruiker die aan het gesprek gekoppeld is, of Anoniem wanneer er geen gebruiker bewaard is. |
| Aangemaakt | Wanneer het gesprek is aangemaakt.                                                              |
| Bijgewerkt | Wanneer het gesprek het laatst is bijgewerkt.                                                   |

Open een gesprek om de volledige chatgeschiedenis te bekijken. Assistentberichten kunnen een ingeklapte tool-calls-sectie bevatten met de
artikels die voor het antwoord gebruikt zijn.

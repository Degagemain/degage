# Contracten

Maak contracten aan en stuur ze ter ondertekening. Een contract begint als concept, wordt verzonden wanneer Documenso de handtekeningflow start,
en is getekend wanneer iedereen heeft getekend. De getekende PDF wordt hier bewaard en kan vanuit de adminzone geopend worden.

| Eigenschap | Beschrijving                                        |
| ---------- | --------------------------------------------------- |
| Gebruiker  | Persoon die moet tekenen.                           |
| Type       | Contracttype (en de bijhorende Documenso-template). |
| Status     | Concept, verzonden of getekend.                     |
| Startdatum | Wanneer het contract start.                         |
| Einddatum  | Optionele einddatum.                                |

Gebruik **Nieuw** om een concept te maken. Vanuit de lijst of detailpagina start **Verzenden** de ondertekening. Bij status getekend opent **PDF
openen** het bewaarde bestand.

# Contracttypes

Beheer herbruikbare contractsoorten. Elk type kan een Documenso-template hebben waarop handtekeningvelden geplaatst worden.

| Eigenschap              | Beschrijving                                                                                                                                               |
| ----------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Code                    | Unieke code en weergavenaam. In te vullen bij het aanmaken (bijvoorbeeld `car-onboarding`) en daarna niet meer te wijzigen. `car-onboarding` wordt geseed. |
| Standaard ondertekenaar | Optionele Dégage-admin die ook moet tekenen. Laat leeg als alleen de eigenaar tekent.                                                                      |
| Standaard kijkers       | Admins die een kopie van het getekende contract ontvangen.                                                                                                 |
| Documenso-template      | Upload een PDF om de template te maken en open Documenso om handtekeningvelden te plaatsen.                                                                |

Gebruik **Nieuw** om een type toe te voegen, of open er een in de lijst om het te bewerken en de template te beheren.

# E-mailtemplates

Beheer de tekst van transactionele e-mails. Elke template wijst naar een Resend-ontwerp (layout) en bewaart de tekstvariabelen in het Engels,
Nederlands en Frans.

| Eigenschap | Beschrijving                                                                                         |
| ---------- | ---------------------------------------------------------------------------------------------------- |
| Code       | Logisch e-mailtype dat bij het versturen wordt gebruikt, zoals e-mailverificatie of wachtwoordreset. |
| Ontwerp    | Resend-layout met de variabelen. Ontwerpen komen uit Resend en worden hier niet bewerkt.             |
| Variabelen | Tekst per taal. Runtime-waarden zoals de knoplink mag je leeg laten.                                 |

Gebruik **Nieuw** naast het zoekveld om een template toe te voegen, of open er een via de naam of de actie **Bewerken** om ontwerp en tekst aan
te passen.

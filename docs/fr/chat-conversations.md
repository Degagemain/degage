# Chats d'assistance

## Objectif

Consultez les conversations d'assistance entre les utilisateurs et l'assistant. Utilisez cette liste pour déboguer les réponses, voir quels
articles de documentation ont été cités et améliorer le système d'aide.

## Propriétés

| Propriété            | Description                                                                                     |
| -------------------- | ----------------------------------------------------------------------------------------------- |
| Canal                | **Chat** (widget d'assistance dans l'app) ou **E-mail** (fil du support par e-mail)             |
| Utilisateur          | Utilisateur connecté ayant démarré le chat, ou **Anonyme** pour les sessions invitées           |
| Titre                | Titre de la conversation défini par l'utilisateur ou dérivé du premier message ; peut être vide |
| Dernière mise à jour | Date de la dernière activité dans la conversation                                               |

Ouvrez une ligne pour lire l'historique complet des messages. Les réponses de l'assistant affichent une liste repliable des articles de
documentation utilisés pour construire la réponse.

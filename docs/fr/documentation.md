# Documentation

Point central pour les textes d’aide issus du dépôt ou des pages manuelles créées dans la zone admin ou via l’API. La liste affiche toutes les
entrées : ouvrez un titre ou **Voir** pour lire, et **Modifier** depuis la page détail ou le menu de ligne. Pour les entrées **manuelles**, le
menu de ligne propose aussi **Supprimer**. **Nouveau** ouvre un formulaire pour créer une documentation manuelle (titre et contenu dans une ou
plusieurs langues, format, public, listes FAQ, groupes). Lors de l’édition, vous pouvez changer le format entre texte brut et Markdown. Pour les
contenus dépôt, l’édition permet de modifier le type, la visibilité de l’article, les groupes et le format — le titre et le texte restent
synchronisés avec le dépôt. Vous ne pouvez pas les supprimer depuis la liste ; ils suivent le dépôt.

Filtrez la liste par type, rôles, listes FAQ, groupe, visibilité de l’article, source et format.

La création ou la modification d’un article met aussi à jour les embeddings de recherche lorsque le titre ou le texte a changé. Utilisez **Plus
→ Synchroniser tous les embeddings** pour relancer les embeddings de tous les articles (par exemple après une mise à jour importante du dépôt).
La synchronisation affiche les compteurs total/mis à jour/ignorés/en échec.

| Propriété               | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| ----------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ID externe              | Identifiant stable ; les docs dépôt utilisent `repo:{sujet}`, manuel souvent `manual:…`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| Source                  | Origine : dépôt (dossier `docs/`) ou manuel (API).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| Format                  | `markdown` ou `text` brut. Vous pouvez le modifier à l’édition.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| Type                    | FAQ ou Article. Les FAQ peuvent apparaître dans les listes FAQ correspondant aux codes sélectionnés.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| Visibilité de l’article | Uniquement pour les articles. Disponible signifie que l’entrée peut apparaître comme article public sur la page Aide & FAQ ; Masqué signifie qu’elle n’y apparaît pas. Les articles masqués peuvent encore servir à répondre aux questions, mais les utilisateurs ne peuvent pas ouvrir la page de l’article. Ce champ est vide pour les FAQ.                                                                                                                                                                                                                                                                                    |
| Public cible            | Qui peut voir la page : public (tout le monde), user (membres connectés) ou admin (administrateurs). Public inclut déjà les utilisateurs et administrateurs, et user inclut déjà les administrateurs ; les rôles qui se recouvrent sont donc réduits au plus large. Dans la liste documentation, chaque rôle attribué apparaît comme un libellé distinct dans la colonne Rôles.                                                                                                                                                                                                                                                  |
| Listes FAQ              | Dans quels widgets FAQ cet élément apparaît. Simulation : infos voiture (`simulation_step_1`) ; résultat accepté, refusé ou examen manuel (`simulation_step_2_approved`, `simulation_step_2_rejected`, `simulation_step_2_review`) ; vos coûts (`simulation_step_3`) ; confirmation (`simulation_step_4`). Onboarding voiture : aperçu et chaque étape (`car_onboarding_all`) plus un code par étape (Connecter Dégage, session d’info, infos utilisateur, infos véhicule, assurance, assistance routière, valeur, autocollants, nom et date de début). Le formulaire d’édition liste chaque code avec l’endroit où il apparaît. |
| Groupes                 | Libellés facultatifs pour classer les articles dans les listes et filtres (gérés dans Groupes de documentation). Le nom affiché suit la langue d’admin choisie.                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| Titre                   | Par langue (anglais, néerlandais, français). Au moins une langue est obligatoire ; les autres peuvent rester vides.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| Contenu                 | Par langue ; le Markdown est pris en charge si le format est markdown. Les langues sans titre ne sont pas enregistrées.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| Embeddings              | Créer ou modifier un article rafraîchit les embeddings de recherche IA si le titre ou le texte a changé. **Plus → Synchroniser tous les embeddings** régénère les embeddings pour chaque langue de chaque article et affiche mis à jour/ignorés/en échec.                                                                                                                                                                                                                                                                                                                                                                        |

## Export

Utilisez **Plus → Exporter** pour télécharger la liste filtrée/triée en CSV ou JSON.

## Import (en masse)

Optionnel : **Plus → Importer** fusionne beaucoup d’enregistrements à partir d’un fichier au même format JSON qu’**Exporter**. Les lignes avec
un id mettent à jour l’enregistrement existant ; les lignes sans id sont ajoutées. Chaque ligne a son propre statut ; un échec n’empêche pas les
autres.

# Utilisateurs

Comptes pouvant se connecter à l'application. Ouvrez un utilisateur depuis son nom ou l'action **Modifier** pour changer les informations
modifiables, y compris le rôle afin d'accorder l'accès admin.

| Propriété             | Description                                                                         |
| --------------------- | ----------------------------------------------------------------------------------- |
| Nom                   | Nom affiché dans l'application.                                                     |
| E-mail                | Adresse e-mail de connexion. Elle ne peut pas être modifiée depuis l'écran d'admin. |
| Rôle                  | **Admin** accède à la zone d'administration ; **Utilisateur** n'y accède pas.       |
| Langue                | Langue utilisée pour l'application et les e-mails.                                  |
| Email vérifié         | Indique si l'utilisateur a confirmé son adresse e-mail.                             |
| Statut                | Les utilisateurs **actifs** peuvent se connecter ; les utilisateurs **bannis** non. |
| Motif du bannissement | Note facultative enregistrée lorsqu'un utilisateur est banni.                       |
| Créé le               | Date de création du compte.                                                         |
| Modifié le            | Date de la dernière modification du compte.                                         |

Il n'y a pas d'action de création ni de suppression ici. Les personnes créent leur compte en s'inscrivant. Il doit rester au moins un admin :
vous ne pouvez pas rétrograder ni bannir le dernier admin.

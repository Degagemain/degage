# Feature flags

Interrupteurs simples qui contrôlent la disponibilité de certaines fonctionnalités. Les flags sont définis par le système ; les administrateurs
peuvent seulement les activer ou les désactiver.

| Propriété   | Description                                               |
| ----------- | --------------------------------------------------------- |
| Code        | Identifiant unique utilisé par l'application.             |
| Description | Courte explication de ce que le flag contrôle.            |
| Activé      | Indique si la fonctionnalité est actuellement disponible. |
| Modifié     | Date de la dernière modification du flag.                 |

# Plans d'assistance routière

Catalogue des plans d'assistance routière proposés aux utilisateurs.

| Propriété   | Description                                       |
| ----------- | ------------------------------------------------- |
| Nom         | Nom affiché du plan d'assistance routière.        |
| Description | Description détaillée de ce que le plan comprend. |
| Actif       | Indique si le plan est disponible à la sélection. |

Utilisez **Nouveau** à côté de la recherche pour ajouter un plan, ou ouvrez-en un via son nom ou l'action **Modifier** pour le mettre à jour (y
compris les noms et descriptions par langue).

## Export

Utilisez **Plus → Exporter** pour télécharger la liste filtrée/triée actuelle en CSV ou JSON.

## Import

Utilisez **Plus → Importer** pour téléverser un fichier JSON obtenu précédemment via Exporter. Les enregistrements avec un id sont mis à jour ;
ceux sans id sont insérés. Chaque ligne affiche son propre statut et un échec n'arrête pas les autres.

# Modèles d'e-mail

Gérez le texte des e-mails transactionnels. Chaque modèle pointe vers un design Resend (mise en page) et stocke les variables de texte en
anglais, néerlandais et français.

| Propriété | Description                                                                                            |
| --------- | ------------------------------------------------------------------------------------------------------ |
| Code      | Type d'e-mail logique utilisé à l'envoi, par exemple la vérification d'e-mail ou la réinitialisation.  |
| Design    | Mise en page Resend qui définit les variables. Les designs viennent de Resend et ne s'éditent pas ici. |
| Variables | Texte par langue. Les valeurs runtime comme le lien du bouton peuvent rester vides.                    |

Utilisez **Nouveau** à côté de la recherche pour ajouter un modèle, ou ouvrez-le depuis son nom ou l’action **Modifier** pour changer le design
et le texte.

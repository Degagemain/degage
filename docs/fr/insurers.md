# Assureurs

Liste de référence des compagnies d'assurance utilisées dans l'application.

| Propriété | Description                |
| --------- | -------------------------- |
| Nom       | Nom affiché de l'assureur. |

## Export

Utilisez **Plus → Exporter** pour télécharger la liste filtrée/triée actuelle au format CSV ou JSON.

## Import

Utilisez **Plus → Importer** pour téléverser un fichier JSON obtenu via Export. Les enregistrements avec un id sont mis à jour ; ceux sans id
sont insérés. Chaque ligne affiche son propre statut ; un échec n'arrête pas les autres.

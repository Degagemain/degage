# Types de contrat

Définissez les types de contrat réutilisables. Chaque type peut pointer vers un modèle Documenso où les champs de signature sont placés.

| Propriété               | Description                                                                                        |
| ----------------------- | -------------------------------------------------------------------------------------------------- |
| Nom                     | Nom affiché dans la zone admin.                                                                    |
| Code                    | Code stable utilisé par l'application, par exemple intégration voiture.                            |
| Signataire par défaut   | Admin Dégage optionnel qui doit aussi signer. Laisser vide si seul le propriétaire signe.          |
| Observateurs par défaut | Admins qui reçoivent une copie du contrat signé.                                                   |
| Modèle Documenso        | Téléversez un PDF pour créer le modèle, puis ouvrez Documenso pour placer les champs de signature. |

Utilisez **Nouveau** pour ajouter un type, ou ouvrez-en un dans la liste pour le modifier et gérer son modèle Documenso.

# Contrats

Créez et envoyez des contrats pour signature. Un contrat commence en brouillon, passe à envoyé lorsque Documenso démarre la signature, et
devient signé lorsque tout le monde a signé. Le PDF signé est conservé ici et peut être ouvert depuis la zone admin.

| Propriété     | Description                                |
| ------------- | ------------------------------------------ |
| Utilisateur   | Personne qui doit signer.                  |
| Type          | Type de contrat (et son modèle Documenso). |
| Statut        | Brouillon, envoyé ou signé.                |
| Date de début | Début du contrat.                          |
| Date de fin   | Date de fin optionnelle.                   |

Utilisez **Nouveau** pour créer un brouillon. Depuis la liste ou la page détail, **Envoyer** lance la signature. Quand le statut est signé,
**Ouvrir le PDF** affiche le fichier conservé.

# Stickers voiture

Catalogue des designs de stickers voiture Dégage parmi lesquels les utilisateurs peuvent choisir.

| Propriété       | Description                                                           |
| --------------- | --------------------------------------------------------------------- |
| Nom             | Nom affiché du design de sticker.                                     |
| Actif           | Si désactivé, le sticker est masqué dans les listes de sélection.     |
| Toujours inclus | Si activé, le sticker est inclus automatiquement pour chaque voiture. |
| Image           | Fichier visuel du sticker (JPEG ou PNG).                              |

## Export

Utilisez **Plus → Exporter** pour télécharger la liste filtrée/triée actuelle en CSV ou JSON.

## Import

Utilisez **Plus → Importer** pour téléverser un fichier JSON obtenu précédemment via Exporter. Les enregistrements avec un id sont mis à jour ;
ceux sans id sont ajoutés. Chaque ligne affiche son propre statut ; un échec n'arrête pas les autres.

# Contracts

Create and send contracts for signature. A contract starts as a draft, becomes sent when Documenso starts the signature flow, and becomes signed
when everyone has signed. The signed PDF is stored here and can be opened from the admin zone.

| Property   | Description                                 |
| ---------- | ------------------------------------------- |
| User       | Person who must sign.                       |
| Type       | Contract type (and its Documenso template). |
| Status     | Draft, sent, or signed.                     |
| Start date | When the contract starts.                   |
| End date   | Optional end date.                          |

Use **New** to create a draft. From the list or detail page, **Send** starts signing. When the status is signed, **Open PDF** shows the stored
file.

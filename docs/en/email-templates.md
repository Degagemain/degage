# Email templates

Manage the copy of transactional emails. Each template points at a Resend design (layout) and stores the text variables in English, Dutch, and
French.

| Property  | Description                                                                                            |
| --------- | ------------------------------------------------------------------------------------------------------ |
| Code      | Logical email type used when sending, such as email verification or password reset.                    |
| Design    | Resend layout that defines the variable slots. Designs are loaded from Resend and are not edited here. |
| Variables | Text filled in per language. Runtime values such as the button link can be left empty.                 |

Use **New** next to the search box to add a template, or open one from its name or the row **Edit** action to change the design and copy.

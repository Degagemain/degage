# Documentation

Central place for help content from the repository or manual entries you add in the admin zone or via the API. The list shows all entries: open
a title or **View** to read, and use **Edit** on the detail page or in the row menu. For **manual** entries, the row menu also includes
**Delete**. **New** opens a form to create manual documentation (title and content in one or more languages, format, audience, FAQ lists, and
groups). When you edit an entry you can change the format between plain text and Markdown. For repository-backed pages, the edit form lets you
change type, article visibility, groups, and format—the headline and body stay synced from the repository. You cannot delete those from the
list; they follow the repository.

Filter the list by type, roles, FAQ lists, group, article visibility, source, and format.

Creating or editing an article also refreshes search embeddings when the title or body changed. Use **More → Sync all embeddings** to refresh
embeddings for every article (for example after a large repository update). Sync reports totals for updated, skipped, and failed records.

| Property           | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| External ID        | Stable identifier; repository docs use `repo:{topic}`, manual entries can use `manual:…`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| Source             | Where the record is managed: repository (seeded from `docs/`) or manual (API).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| Format             | `markdown` or plain `text`. You can change this when editing.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| Type               | FAQ or Article. FAQ items can appear in FAQ lists that match the selected codes.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| Article Visibility | Only for articles. Available means the item can appear as a public article on the Help & FAQ page; Hidden means it does not. Hidden articles can still be used to answer questions, but people cannot open the article page. This field is empty for FAQ items.                                                                                                                                                                                                                                                                                                    |
| Audience           | Who may view the page in the app: public (everyone), user (signed-in members), or admin (administrators). Public already includes users and admins, and user already includes admins, so overlapping roles are reduced to the widest one. In the documentation list, each assigned role appears as its own label in the Roles column.                                                                                                                                                                                                                              |
| FAQ Lists          | Which FAQ widgets show this item. Simulation: car details (`simulation_step_1`); result approved, rejected, or manual review (`simulation_step_2_approved`, `simulation_step_2_rejected`, `simulation_step_2_review`); your costs (`simulation_step_3`); confirmation (`simulation_step_4`). Car onboarding: overview and every step (`car_onboarding_all`) plus a code per step (Connect Dégage, info session, user info, car info, insurer, road assistance, car value, stickers, car name and start date). The edit form lists each code with where it appears. |
| Groups             | Optional labels used to organise articles in the list and filters (managed under Documentation groups). Each group name is shown in your chosen admin language.                                                                                                                                                                                                                                                                                                                                                                                                    |
| Title              | Per language (English, Dutch, French). At least one language is required; the others can be left empty.                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| Content            | Per language; Markdown is supported when format is markdown. Languages without a title are not saved.                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| Embeddings         | Creating or editing an article refreshes AI-search embeddings when title or body changed. **More → Sync all embeddings** regenerates embeddings for every language of every article and reports updated, skipped, and failed counts. Support chat RAG retrieves vector chunks then loads **full** page text for the top matching documents.                                                                                                                                                                                                                        |

## Export

Use **More → Export** to download the current filtered/sorted list as CSV or JSON.

## Import (bulk)

Optional: **More → Import** merges many records from one file in the same JSON shape as **Export**. Rows that include an id update existing
records; rows without an id are added. Each row reports its own outcome; one failure does not stop the rest.

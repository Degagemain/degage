# Users

Accounts that can sign in to the app. Open a user from the name or the row **Edit** action to change editable details, including the role so you
can grant admin access.

| Property       | Description                                                          |
| -------------- | -------------------------------------------------------------------- |
| Name           | Display name shown in the app.                                       |
| Email          | Sign-in email address. This cannot be changed from the admin screen. |
| Role           | **Admin** can open the admin area; **User** cannot.                  |
| Language       | Language used for the app and emails.                                |
| Email verified | Whether the user has confirmed their email address.                  |
| Status         | **Active** users can sign in; **Banned** users cannot.               |
| Ban reason     | Optional note stored when a user is banned.                          |
| Created        | When the account was created.                                        |
| Updated        | When the account was last changed.                                   |

There is no create or delete action here. People create their own accounts by signing up. At least one admin must remain: you cannot demote or
ban the last remaining admin.

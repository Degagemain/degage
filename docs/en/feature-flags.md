# Feature flags

Simple on/off switches that control whether certain features are available. Flags are defined by the system; admins can only turn them on or
off.

| Property    | Description                                  |
| ----------- | -------------------------------------------- |
| Code        | Unique identifier used by the application.   |
| Description | Short explanation of what the flag controls. |
| Enabled     | Whether the feature is currently available.  |
| Updated     | When the flag was last changed.              |

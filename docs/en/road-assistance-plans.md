# Road Assistance Plans

Catalog of road assistance plans offered to users.

| Property    | Description                                     |
| ----------- | ----------------------------------------------- |
| Name        | Display name of the road assistance plan.       |
| Description | Detailed description of what the plan includes. |
| Active      | Whether the plan is available for selection.    |

Use **New** next to the search box to add a plan, or open one from its name or the row **Edit** action to change it (including names and
descriptions per language).

## Export

Use **More → Export** to download the current filtered/sorted list as CSV or JSON.

## Import

Use **More → Import** to upload a JSON file previously obtained via Export. Records with an id are updated; records without an id are inserted.
Each row shows its own status, and one failure does not stop the others.
